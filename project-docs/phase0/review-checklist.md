# Phase 0 评审清单

以下决策影响第一阶段数据库、权限和对外协议。评审时逐项标记“接受/修改”，记录负责人和日期；未决定的事项不进入依赖它的 POC。

| 决策 | 当前建议 | 需确认的业务边界 |
| --- | --- | --- |
| 交付模式 | 企业内部及业务系统嵌入 | 是否对外 SaaS、私有化交付、OEM |
| 租户模型 | 共享元数据库逻辑隔离 | 是否存在必须独立实例的客户 |
| 用户关系 | 一人可加入多租户 | 账号合并规则与切换体验 |
| 平台管理员 | 默认不可读租户业务数据 | 代理进入和紧急访问审批 |
| 资源归属 | 资源必须有唯一租户 | 是否允许跨租户共享模板或看板 |
| 删除与保留 | 先停用，延迟清理 | 保留期、恢复期、备份处理 |
| 行规则 | 允许规则并集，强制限制交集 | 无规则时是否全部拒绝，白名单范围 |
| 外部身份 | OIDC Subject 唯一映射 | IdP、组织/角色同步策略 |
| 嵌入 | 后端换一次性 Ticket | 首个宿主系统、域名、资源与交互范围 |
| 容量 | 首期单节点 | 租户数、用户数、并发、看板数量 |
| 合规 | 保留 DataEase 品牌与版权 | 是否需要闭源/OEM 授权审查 |

技术评审同时检查：正式版源码构建报告、完整表所有权清单、Native SQL/缓存/文件/任务风险入口清单、配置与 Secret 注入、测试环境和回滚演练方案。当前未通过项详见 [验证状态](verification.md)。
