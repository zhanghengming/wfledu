# ADR-001：正式版基线与许可证

状态：建议，待评审。日期：2026-09-29。

决定：以 DataEase `v3.1.0`、提交 `5ce2c3e5d2c99c5d2e8ab8aed2b0fa622f4da594` 作为首期基线。使用社区版公开源码；`de-xpack` 仅保留上游子模块指针，不拉取、复制或移植其实现。保留 DataEase Logo 和版权信息。

理由：正式标签可追溯，近期安全修复已包含在该版本中；上游 `dev-v3` 是开发线，构建依赖与契约可能变化。根 `LICENSE` 是带附加条件的 GPLv3 修改版，交付模式和衍生作品义务需由项目方在发布前做法务确认。

影响：版本升级按发布标签评估；闭源交付、OEM 或更换品牌须另行取得明确授权。源码构建仍需在合适工具链中验证。
