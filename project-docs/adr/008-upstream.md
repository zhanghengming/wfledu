# ADR-008：迁移与上游同步

状态：建议，待评审。日期：2026-09-29。

决定：沿用 DataEase V3 的 `SqlBlock` / `InitSqlListener` 迁移机制，企业迁移使用独立版本组并与现有执行顺序兼容；不重写已执行版本。上游安全版本进入单独升级分支，先比对核心补丁和迁移，再做回归。

理由：源码已有启动迁移和 `de_standalone_version` 记录；叠加另一套未经协调的迁移器会造成顺序与表结构冲突。

影响：企业版本组的具体编号和执行位置必须通过启动 POC 验证。升级先备份，生产库不启用自动 `ddl-auto:update` 作为唯一变更手段。项目远端因上游旧历史中的敏感凭据采用源码树快照，后续升级按官方版本树差异移植，不能直接合并上游历史。
