# W05社区源码审视与待验证设计事项

2026-10-09。关联[W05工作包](../planning/w05-business-query.md)、[统一授权查询](authorization-query.md)、[MySQL字典](mysql8-table-dictionary.md)和[DDD一致性](ddd-consistency.md)。本记录区分源码事实与设计候选，不是已实施方案或运行验收。业务依然为集团独立数据库、集团内共享表、学校×数据集×操作授权；不按集团名称、角色名称或固定财务表写特判。

## 已核对的公共源码事实

| 源码接点 | 实际行为与影响 |
| --- | --- |
| sdk/common的CoreDatasource/CoreDatasetGroup/CoreDatasetTable/CoreDatasetTableField | 原生元数据与企业归属侧表分别存储；字段和依赖必须从服务端完整读取，不能信任浏览器列表 |
| OrganizationTransactionKernel.school及PermissionDecisionService | 授权学校集合是组织主键；受控SchoolReference同时包含学校编号和归属/修订，执行前须转换并核对 |
| DatasetSQLManage.getUnionSQLForEdit | SQL、dsMap、JOIN描述和tableFieldWithValues一起构造；SQL数据集还有SQL变量处理，不能只检查第一数据源 |
| ChartDataManage.calcData及图表Handler | SQLMeta交给原生Handler计算；学校过滤必须影响其聚合前输入，查询后删除结果不能纠正已计算的汇总 |
| WhereTree2Str及SQLMeta | 普通权限树存在OR合并；SQLMeta没有独立企业强制条件的参数集合，不可直接追加学校权限树后假定硬AND |
| CalciteProvider.getConnectionFromPool/update/delete | 池按数据源ID/模式别名复用；更新/删除有关闭和替换机制，但ID本身没有证明当前绑定与配置修订 |
| CalciteProvider参数执行 | 支持PreparedStatement及TableFieldWithValue，也存在参数值日志和异常追加值的路径；复用时需验证脱敏，而非只包装HTTP错误 |
| ManagementRequestFilter/PermissionFactLoader | 企业旧查询入口关闭；当前权限事实依赖所属短事务、当前集团/身份修订。新查询要完整接入，不能使用社区替补允许掩盖缺失策略 |

没有读取或复制XPack实现；以上事实来自社区与已实现的自研模块。商业公开能力仅作为既有需求参照，不证明本项目已经拥有相同执行能力。

## 设计候选和实际证明门槛

1. **存储边界与数据权限分开。** 源核验负责数据库、只读权限和配置状态；权限域负责主体/资源/操作及学校范围。查询应用服务必须同时取得两者当前事实，不能把网络连接成功当作授权成功。
2. **受控数据集结构。** 先证明可支持结构，再明确开放范围；不能默默把任意SQL、视图、跨源JOIN/联合集和插件算作支持。任何依赖、学校字段或表达式无法核验就拒绝启用。不支持项必须在页面、接口和验收限制一致展示。
3. **学校编号比较。** 由有效本集团SCHOOL组织映射出业务编号；字符类型、大小写、字符集和尾空格都要实际验证，数据库默认不敏感比较不能把未登记的近似编号放行。学校字段的业务含义仍由可信管理配置和业务样本确定，技术类型检查不能替代业务确认。
4. **聚合前硬约束与参数一起传递。** 候选是把经过验证的原生基础SQL封装为受控学校筛选输入，再交给原生Handler；是否可行需证明方言转换、别名、动态参数位置、SUM/COUNT、排序/分页和所有开放Handler。不得在POC之前承诺只改一处或零核心改动。
5. **服务端重建请求。** 新HTTP只接受有界资源/字段/操作与结构化筛选，不接受用户、集团允许范围、SQL、任意ChartViewDTO或源码开关作为执行事实。图表和数据集配置从服务端当前归属加载；用户筛选只收窄硬范围。
6. **连接与缓存版本。** 每次使用核对数据源/绑定状态及当前配置摘要；源变更后旧池不得以相同ID继续当作新验证结果。原生缓存键和可变对象也需审视；未证明隔离前不能复用旧结果缓存，明确关闭相关路径可作为阶段方案，但不能声称缓存功能已验收。
7. **事务与交付。** 元数据库短事务产出不可变执行快照，外部查询不占长元事务；查询后、缓存命中和响应交付前重新核对当前权限/绑定。仅在服务方法中重查一次不能证明序列化交付前的撤权竞态，须真实阻塞请求、撤权提交、放行结果验证。
8. **异步缺失上下文拒绝。** Handler/Provider若切换线程，桥接上下文必须显式传递与清理；缺失不能回到社区默认路径。初始化、监控和用户取数分别识别，不把系统背景活动当作无限用户授权。
9. **结构修改与授权变化。** 数据集定义、学校字段或源重绑定可能改变既有权限代表的数据内容；需明确哪些能力可修改、如何使旧绑定/决策失效，以及是否需要重新授权或新资源版本。现有管理资格独立，不能因MANAGE_DATASOURCE_BINDINGS存在就隐式取得MANAGE_AUTHORIZATION或数据导出能力。
10. **增量迁移。** 字典第18—21表尚待实施；按新版本增加，冻结4.1—4.7不改写。沿已有生产级字段注释、外键、CHECK、索引/版本核验，空库/存量/失败重试/冷加载和完整包测试同步完成。
