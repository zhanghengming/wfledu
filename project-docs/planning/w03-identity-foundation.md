## 第一个开发单元

先完成集团/学校权威映射的领域与持久化设计，以及所依赖的全局用户和集团成员。使用字典中的de_ent_user、de_ent_tenant、de_ent_tenant_member、de_ent_org，字段/索引以字典为主，不在本文再造一套表结构。

- 学校code全局唯一，停用不释放；部门父节点/所属学校只能属于同一集团，组织树不能成环，未知学校不推断归属。
- 用户全局身份与集团成员分开；平台专属资格不要求伪造成每个集团的普通成员。集团管理员及学校角色均不能自动获得平台资格。
- 租户默认DISABLED；元数据创建不意味着业务数据库绑定已验证，不自动启用集团或授予数据查看。
- 迁移先核对真实SqlBlock扫描、版本组与顺序，处理created_by/updated_by对全局用户的依赖；自引用和受控初始化不得用默认社区admin替代。
- 持久化沿JPA/QueryDSL及现有异常体系；明确乐观锁、同集团复合外键、事务和显式清空，不假设save(null)可以清空字段。

当前先交付[4.1基础迁移](../development/foundation-migration.md)，避免JPA自动DDL抢跑；随后实现领域/JPA、学校权威映射与显式事务更新。该单元先做领域/迁移实现与隔离验证；认证和管理资格未齐前，不开放可由浏览器创建、编辑或切换集团的公共接口。
