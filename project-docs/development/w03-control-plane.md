# W03连续实施设计与验证记录

## 模块与版本边界

4.1/4.2已执行定义不变。4.3新增组织成员、角色、成对任职、任职学校、类型主体和管理能力六表；4.4新增正式密码凭据、平台资格和管理会话；4.5新增资源归属。新表采用JPA与显式短事务；当前目标独立演进，各历史迁移只检查自身冻结结构，默认关闭不建表／供给账号。

集团管理资格不由成员标记、角色名称或业务VIEW推导。主体为ORG／ROLE／USER，USER绑定当前集团成员；有效组织成员／角色任职均重新核对状态和有效组织链，任职学校保留配对。管理能力是集团级、允许来源合并、禁止优先，当前集团必须匹配。首次管理资格通过显式受控初始化建立，公共接口不能任意授予平台资格。

## 控制面开放边界

W03只开放新的管理接口，不提前实现W04/W05分析授权适配。完整enterprise.enabled的既有严格装配门槛保持，不使用假行列权限Bean满足启动。新增显式enterprise.management.enabled（默认false）仅开放W03控制面；必须foundation=true，正式凭据／资格／会话／迁移和请求就绪齐备。管理模式拦截旧业务API、分享、导出、文件及嵌入入口，不能回落社区替补放行；关闭时社区兼容行为保持。两个模式同时开启须明确拒绝，未来完整企业装配再整合。

新的登录／改密／退出／集团切换／成员组织管理／资源归属通过SDK API与DTO、server、manage、JPA调用。使用现有ResultMessage／PageResult／DEException。管理会话使用32随机字节Bearer，服务端只存SHA256摘要，凭据不是用户ID；密码PBKDF2-HMAC-SHA256≥600000、独立盐、256位输出，不使用社区MD5。登录失败原子累计及锁定，身份修订变更立即撤销旧会话；强制改密会话只能改密／退出。浏览器不能提交tenant/user/role作为身份。

请求就绪在迁移、当前结构验证及初始化状态核验完成后开放；就绪前所有控制面请求拒绝，异常／失败不进入宽松模式。请求结束清理AccessContext，切换通过会话版本CAS及资格重新核验。平台PLATFORM_OPERATE和GROUP_READ_ALL独立，控制面资格不获得业务全读，全读仅当前集团VIEW，不包含编辑／导出。

## 初始化与测试区

初始化只从专用测试用户本机私有输入执行，验证文件权限、数据库／任务目录及全部目标，空状态原子建立账号／资格／审计；重复初始化拒绝或按同一状态安全确认，不能扩大既有资格。不使用公开注册、默认密码或请求头临时管理员。原13306／16379／18100兼容测试保持，控制面运行采用同一专用任务区的独立loopback端口和新合成元库，实际目标在创建前核对并留证；不动旧库／目录／服务。秘密不输出、入Git或Markdown。
