## 第5步设计复核

领域输入显式携带目标用户、集团、身份修订、集团修订、资源版本、有效学校及主体绑定，不访问JPA或ThreadLocal。ROLE每条规则先与其对应任职学校求交，再合并；ORG只匹配直接成员，不继承父组织授权。EXPORT/DRILL与VIEW求交，EDIT要求VIEW；平台资格只例外允许当前集团VIEW。

事实在现有集团短事务读锁内加载，管理写入继续获取同一集团写锁；目标用户在当前身份事务校验，不替换操作者。按目标主体、资源和操作批量读取授权与关联学校，层级包含parent和显式school依赖。不保存决策缓存。超过明确有界预算时拒绝，不能接受截断的授权集合。

预览使用严格JSON契约，仅MANAGE_AUTHORIZATION可调用。输出策略结果、来源和修订，不返回SQL／样本。W04数据预览始终标记executionReady=false；受控资源实际查看还必须校验原生空画布及METADATA_ONLY策略。拒绝扩大旧取数、编辑、导出、嵌入接口。
