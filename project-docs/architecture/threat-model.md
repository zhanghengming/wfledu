# 威胁模型与安全基线

保护对象：租户元数据、业务数据、数据源凭据、嵌入密钥、用户身份、导出文件和审计记录。信任边界位于浏览器/后端、宿主系统/DataEase、DataEase/业务数据库、租户之间。

| 威胁 | 入口 | 设计控制 | 发布验证 |
| --- | --- | --- | --- |
| 跨租户读取/修改 | IDOR、搜索、批量 API、原生 SQL | 服务端租户上下文、所有权检查、查询约束 | A/B 双租户越权矩阵 |
| 缓存或任务串租户 | Redis/JCache、线程池、Quartz | 租户化键、显式上下文、finally 清理 | 并发和复用线程测试 |
| SQL 注入 | 自定义 SQL、筛选参数、行权限 | AST 白名单、参数绑定、标识符校验 | 恶意字段/值测试 |
| Ticket 重放和越权 | 嵌入入口 | 短期、资源绑定、原子消费、撤销 | 重放、改资源、改租户测试 |
| Secret 泄漏 | 前端、日志、配置 | 后端换票、加密存储、日志脱敏 | 前端产物和日志检查 |
| SSRF / 驱动风险 | 数据源 URL、插件和上传 | 地址策略、驱动来源控制、最小权限 | 内网探测和恶意驱动测试 |
| 文件越权和路径穿越 | 上传、导出、下载 | 服务端解析键、规范化路径、再次鉴权 | 路径与跨租户测试 |
| 嵌入页面劫持 | iframe、postMessage | CSP Origin 白名单、消息版本与来源检查 | 非白名单域名测试 |

生产默认拒绝未知租户和未知权限；异常响应不暴露 SQL、凭据、内部路径。管理员代理、权限变更、导出和密钥操作必须审计。依赖与镜像漏洞扫描在发布门禁运行，安全修复优先跟踪官方发布版本。
