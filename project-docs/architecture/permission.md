# 身份与权限架构

## 身份模型

平台用户、租户成员、组织成员和外部身份映射分开建模。外部身份唯一键为 `(tenant_id, provider, external_subject)`；不能只按姓名、手机号或邮箱合并账号。首期保留本地登录，并新增 OIDC Authorization Code + PKCE 或后端机密客户端流程。JIT 自动创建默认只赋查看角色。

现有社区替补登录 `SubstituleLoginServer` 只允许 `admin`，不能作为多用户体系。现有 `@DePermit`、`DeLinkPermit`、`CorePermissionManage` 和 `PermissionManage` 应作为兼容入口逐步接入自研实现；可选注入的行列权限缺失场景必须在企业模式下拒绝受保护的数据访问。

## 授权顺序

```text
租户有效 → 用户/应用有效 → 成员关系 → 操作权限 → 资源所属租户 → 资源授权 → 数据行列策略 → 配额
```

任一环节失败即拒绝。平台管理员进行租户运维操作使用单独的管理接口和审计，不自动拥有业务资源读取权。

| 对象 | 首期动作 |
| --- | --- |
| 菜单 | 可见、可进入 |
| 资源 | 查看、编辑、管理、授权、分享、嵌入、导出 |
| 数据集 | 查询、预览、管理、导出明细 |
| 嵌入应用 | 换票、访问指定资源、允许的交互和导出 |

## 行列规则

- 策略用结构化 AST 表示：字段来自数据集元数据，操作符为受控枚举，值以绑定参数传递。首期不支持任意 SQL 片段。
- 同一授权域内的允许行规则取并集；强制租户过滤和显式拒绝规则始终取交集。无匹配允许规则时拒绝数据访问。具体业务例外需评审后写成用例。
- 列禁用在元数据和查询投影阶段生效；脱敏在服务端执行。若同一列同时命中禁用和脱敏，禁用优先。
- 预览、图表、下钻、计算字段、缓存、导出、分享、嵌入和 API 必须共用策略决策；任何绕过路径列为阻断发布缺陷。
- 权限规则变更增加策略版本并驱逐相关缓存。审计记录变更人、范围和版本，不记录敏感明文值。

权限矩阵和策略 DSL 的具体字段在 POC 中冻结。实现前需要给每个读写 API 标明对应动作和资源，生成越权测试用例。
